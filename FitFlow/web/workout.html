The WorkoutPlanner instantiates concrete subclasses of WorkoutRoutine (e.g. StrengthRoutine, CardioRoutine, HIITRoutine, FlexibilityRoutine). Each subclass overrides calculateEstimatedCaloriesBurned() using task-specific Metabolic Equivalent of Task (MET) multipliers. Zero hardcoded routine data is embedded in HTML/JS.
