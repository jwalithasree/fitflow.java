Mathematical Formula
📐

Quetelet Index (BMI)

BMI = Weight (kg) / [Height (m)]²

Height is converted from centimeters to meters and squared. Handled directly by BMICalculator.compute().

OOP Architecture
🏗

Encapsulated Calculation

Implements HealthCalculator<BMIResult> generic interface. Returns an immutable value object encapsulating value, WHO category, advice, and range.

Exception Safety
🛡

Invariant Validation

Values of height or weight ≤ 0 immediately throw InvalidHealthDataException in Java, preventing division by zero and bad state propagation.
